# FitNotes — Body Tracker (referencia oficial)

Fuente: https://www.fitnotesapp.com/body_tracker/

---

## Descripción general

El Body Tracker permite registrar y monitorizar el progreso de un rango de medidas personalizables. Aunque está diseñado principalmente para métricas físicas como peso y grasa corporal, soporta cualquier medida rastreable, incluidos datos nutricionales.

**Acceso:** menú overflow en la pantalla de inicio → Body Tracker.

---

## Configuración

### Medidas por defecto
El sistema incluye dos medidas habilitadas de serie: **Body Weight** y **Body Fat**. Hay medidas adicionales comunes disponibles pero desactivadas por defecto.

### Activar medidas
Se activan marcando la casilla correspondiente. Al habilitarse, aparecen en las pantallas Track, History y Graph. **Deshabilitar una medida NO elimina los valores ya registrados.**

### Crear medidas personalizadas
Al añadir una medida personalizada se puede:
- Introducir un nombre personalizado
- Seleccionar unidades predefinidas (kg, lbs, cm, in, %) o crear unidades nuevas
- Definir un objetivo:
  - **Increase** (aumentar): las flechas verdes indican ganancias de valor
  - **Decrease** (disminuir): las flechas verdes indican reducciones de valor
  - **Specific Value** (valor específico): define un objetivo que se muestra en las gráficas de progreso

### Gestión de medidas
- Las medidas personalizadas se pueden editar (nombre, unidad, objetivo) y eliminar completamente
- Las medidas por defecto no se pueden renombrar ni eliminar, aunque sí deshabilitar y reemplazar por alternativas personalizadas
- Función de reset: elimina todos los valores registrados de una medida

### Organización
Las medidas se pueden reordenar manteniendo pulsado el icono de arrastre y reposicionando el elemento.

---

## Track (Registro)

La pantalla Track muestra las medidas habilitadas con:
- Valor más reciente
- Cambio respecto a la lectura anterior (ej.: +0.5 kg)
- Tiempo transcurrido desde la última entrada

Para registrar: introducir el nuevo valor, comentario opcional y timestamp ajustable.

---

## History (Historial)

La pantalla History organiza las medidas registradas por fecha, mostrando los deltas con código de color basado en los objetivos definidos. Se puede filtrar por medida específica mediante un selector desplegable.

---

## Graph (Gráfica)

La pantalla Graph visualiza las tendencias de cada medida, muestra el objetivo definido cuando aplica, y permite seleccionar puntos de datos concretos para ver las medidas relacionadas de esa fecha.
