# FitNotes — Glossary (referencia oficial)

Fuente: https://www.fitnotesapp.com/glossary/

---

## 1RM (One Rep Maximum)

El 1RM es la cantidad máxima de peso que se puede levantar para una única repetición de un ejercicio dado. Monitorizar esta métrica ayuda a medir el desarrollo de la fuerza a lo largo del tiempo.

---

## Estimated 1RM (1RM Estimado)

En lugar de testear el máximo real regularmente (lo que exige un esfuerzo físico considerable), se puede calcular una aproximación mediante métodos matemáticos establecidos.

FitNotes utiliza la **Fórmula de Brzycki** (desarrollada por Matt Brzycki) para derivar estimaciones del 1RM a partir de series completadas:

```
1RM = weight × (36 / (37 - reps))
```

> **Importante:** esta fórmula es razonablemente precisa para series de esfuerzo máximo de **2-10 repeticiones**, pero puede volverse cada vez más imprecisa a medida que aumenta el número de repeticiones, por lo que debe usarse solo como referencia.
