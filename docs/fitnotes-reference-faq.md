# FitNotes — FAQ (referencia oficial)

Fuente: https://www.fitnotesapp.com/faq/

---

## ¿Cómo puedo apoyar el proyecto?

Se puede adquirir la app **FitNotes Supporter** en Google Play para ayudar a financiar el desarrollo. Esta compra desbloquea tipos de ejercicio adicionales. También se puede apoyar el proyecto valorando FitNotes en Google Play.

---

## ¿Está FitNotes disponible para iOS?

No. FitNotes está disponible **exclusivamente para Android**. Actualmente no hay planes de desarrollar una versión para iOS/iPhone.

---

## ¿Cómo puedo solicitar una nueva funcionalidad?

El equipo considera las sugerencias de funcionalidades aunque no puede implementar todas las solicitudes. Se puede contactar con ellos detallando la funcionalidad deseada. Todo se tiene en cuenta y puede influir en las próximas versiones.
