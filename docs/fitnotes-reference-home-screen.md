# FitNotes — Home Screen (referencia oficial)

Fuente: https://www.fitnotesapp.com/home_screen/

---

## Descripción general

La pantalla de inicio se muestra al lanzar la app y es el hub central para acceder a los entrenamientos. Se puede navegar entre entrenamientos deslizando o usando los botones de navegación para ver los registros de ejercicios de distintas fechas.

---

## Componentes principales de la UI

| # | Elemento | Descripción |
|---|---|---|
| 1 | **Fecha del entrenamiento** | Muestra la fecha actual del entrenamiento; permite volver rápidamente a la sesión de hoy |
| 2 | **Icono de calendario** | El calendario resalta las fechas en que se entrenó y permite revisar fácilmente entrenamientos pasados |
| 3 | **Botón añadir ejercicio** | Permite seleccionar e insertar nuevos ejercicios en el entrenamiento actual |
| 4 | **Menú overflow** | Permite navegar a otras partes de la app, incluyendo Ajustes y Body Tracker |
| 5-6 | **Flechas de navegación** | Botones de día anterior/siguiente para navegar secuencialmente entre entrenamientos |
| 7 | **Iniciar nuevo entrenamiento** | Inicia una sesión nueva con selección de ejercicios |
| 8 | **Copiar entrenamiento anterior** | Si se quiere repetir un entrenamiento previo, se puede copiar y hacer ajustes |
| 9 | **Registro de ejercicios** | Muestra las series registradas de cada ejercicio para la fecha seleccionada |

---

## Gestión de entrenamientos

### Comentar un entrenamiento
Se pueden adjuntar notas a los entrenamientos para referencia futura mediante el menú overflow.

### Cronometrar un entrenamiento
Se puede usar el temporizador de entrenamiento para registrar la hora de inicio, hora de fin y duración de cada sesión. Disponible en modo automático y manual, con opción de inicio automático.

### Compartir un entrenamiento
Genera una representación legible en texto del entrenamiento que se puede compartir en redes sociales.

### Copiar un entrenamiento
Duplica entrenamientos anteriores con selección personalizable de ejercicios y series.

### Mover un entrenamiento
Traslada entrenamientos a otras fechas usando la interfaz de calendario.

### Eliminar un entrenamiento
Mantener pulsado un ejercicio hasta que quede seleccionado permite eliminar ejercicios individuales o múltiples.

### Reordenar un entrenamiento
Funcionalidad de arrastrar y soltar para reorganizar ejercicios dentro de una sesión de entrenamiento.
